Lap replay

Sectors: time of each lap (click a row to zoom in; the laps then start together at the sector entry)

The 12 style numbers of each lap, as they are (each in its own unit)

3D chase camera: the camera follows the chosen lap from behind; every lap is a car on the road and its racing line is drawn on the asphalt, so you see how each one takes the corner. "At the same place" puts all cars at the same distance along the track, so only the line and the speed differ; "at the same moment" is a live race in which the faster laps pull away. Drag = look around the car, wheel = closer / further, double-click = reset the camera. Bottom left of the view: speed, brake (red) and throttle (green) of each lap.
All laps are the same car on the same track in the simulator, started on the line. In a sector view they all start at the sector entry at the same moment. "gap" = the seconds this lap needs less (-) or more (+) than the driver's run to reach the place where it is now (in a sector view: counted from the sector entry). "ahead" = metres in front of the driver's run at the same moment.
