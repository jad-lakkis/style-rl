Lap replay

Sectors: time of each lap (click a row to zoom in; the laps then start together at the sector entry)

The 12 style numbers of each lap: value, and distance from the target in spread units

All laps are the same car on the same track in the simulator, started on the line. In the whole-lap view they run side by side in time; in a sector view they all start at the sector entry at the same moment, so what you see is only what happens inside the sector. "gap" = the seconds this lap needs less (-) or more (+) than the driver's run to reach the place where it is now (in a sector view: counted from the sector entry). "ahead" = metres in front of the driver's run at the same moment. 3D: height = speed (turn it off or change the exaggeration at the top); the thin line under a dot goes down to the track. Drag = turn, wheel = zoom, double-click = reset the view.
